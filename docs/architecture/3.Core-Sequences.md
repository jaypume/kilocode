## 时序图 A: 用户聊天（流式）从触发到渲染

```mermaid
sequenceDiagram
    participant User as 用户
    participant Webview as Webview<br/>(React)
    participant Provider as ClineProvider
    participant Task as Task
    participant Context as 上下文管理
    participant API as LLM API
    participant UI as UI 更新

    User->>Webview: 输入消息 + 图像
    Webview->>Provider: postMessage({ type: "newTask" })

    Provider->>Provider: initClineWithTask()
    Provider->>Task: new Task(options)
    Task->>Task: startTask(task, images)

    Task->>Task: say("text", task, images)
    Task->>Provider: postStateToWebview()
    Provider->>Webview: postMessage({ type: "state" })
    Webview->>UI: 渲染用户消息

    Task->>Task: recursivelyMakeClineRequests([userContent])

    Note over Task: 主循环开始

    Task->>Task: 检查 abort 标志
    Task->>Task: 检查 consecutiveMistakeCount

    Task->>Context: processKiloUserContentMentions()
    Context->>Context: 解析 @file, @url, @problems
    Context-->>Task: parsedUserContent

    Task->>Context: getEnvironmentDetails()
    Context->>Context: 收集文件列表、Git 状态、诊断信息
    Context-->>Task: environmentDetails

    Task->>Task: addToApiConversationHistory({ role: "user", content })

    Task->>Task: say("api_req_started")
    Task->>Provider: postStateToWebview()
    Provider->>Webview: postMessage({ type: "state" })
    Webview->>UI: 显示加载动画

    Task->>API: createMessage(systemPrompt, messages, metadata)
    API-->>Task: stream (AsyncGenerator)

    Note over Task,API: 流式处理开始

    loop 每个 chunk
        API->>Task: chunk (text/reasoning/tool_call_partial/usage)

        alt chunk.type = "text"
            Task->>Task: assistantMessage += chunk.text
            Task->>Task: say("text", assistantMessage, partial=true)
            Task->>Provider: postStateToWebview()
            Provider->>Webview: postMessage({ type: "partialMessage" })
            Webview->>UI: 实时渲染文本
        else chunk.type = "reasoning"
            Task->>Task: reasoningMessage += chunk.text
            Task->>Task: say("reasoning", reasoningMessage, partial=true)
            Task->>Provider: postStateToWebview()
            Provider->>Webview: postMessage({ type: "partialMessage" })
            Webview->>UI: 实时渲染推理
        else chunk.type = "tool_call_partial"
            Task->>Task: NativeToolCallParser.processRawChunk(chunk)
            Task->>Task: assistantMessageContent.push(toolUse)
            Task->>Task: presentAssistantMessage()
            Task->>Provider: postStateToWebview()
            Provider->>Webview: postMessage({ type: "partialMessage" })
            Webview->>UI: 显示工具调用骨架
        else chunk.type = "usage"
            Task->>Task: 累积 token 统计
        end
    end

    Note over Task,API: 流式处理完成

    Task->>Task: 更新 api_req_started 消息 (token/cost)
    Task->>Task: saveClineMessages()
    Task->>Provider: postStateToWebview()
    Provider->>Webview: postMessage({ type: "state" })
    Webview->>UI: 显示最终消息 + token 统计

    Note over Task: 如果有工具调用，进入工具执行流程
    Note over Task: 如果 attempt_completion，请求用户确认
    Note over Task: 如果有新的 userMessageContent，继续循环
```

## 时序图 B: LLM 输出编辑建议 → apply edits → 写回文件

```mermaid
sequenceDiagram
    participant LLM as LLM API
    participant Task as Task
    participant Parser as NativeToolCallParser
    participant Tool as WriteToFileTool
    participant Approval as 自动批准
    participant User as 用户
    participant DiffView as DiffViewProvider
    participant FS as File System
    participant Tracker as FileContextTracker

    LLM->>Task: stream chunk (tool_call_partial)
    Task->>Parser: processRawChunk(chunk)
    Parser->>Parser: 累积工具参数 JSON
    Parser-->>Task: tool_call_start event

    Task->>Task: assistantMessageContent.push({ type: "tool_use", name: "write_to_file" })
    Task->>Task: presentAssistantMessage()

    LLM->>Task: stream chunk (tool_call_partial) [继续]
    Task->>Parser: processRawChunk(chunk)
    Parser->>Parser: 增量解析 JSON (partial-json)
    Parser-->>Task: tool_call_delta event

    Task->>Task: 更新 assistantMessageContent
    Task->>Task: presentAssistantMessage()

    LLM->>Task: stream end
    Task->>Parser: finalizeStreamingToolCall()
    Parser-->>Task: 完整的 ToolUse

    Note over Task: 流式处理完成，开始执行工具

    Task->>Task: executeTool(toolUse)
    Task->>Tool: execute({ path, content }, task, callbacks)

    Tool->>Tool: 验证参数 (path, content)

    Tool->>Task: rooIgnoreController.validateAccess(path)
    Task-->>Tool: accessAllowed = true

    Tool->>Task: rooProtectedController.isWriteProtected(path)
    Task-->>Tool: isWriteProtected = false

    Tool->>FS: fileExistsAtPath(path)
    FS-->>Tool: fileExists = true

    Tool->>FS: fs.readFile(path)
    FS-->>Tool: originalContent

    Tool->>Tool: createPrettyPatch(original, new)
    Tool->>Tool: computeDiffStats(unified)

    alt Prevent Focus Disruption 实验开启
        Tool->>Tool: 构建 completeMessage (unified diff)
        Tool->>Approval: checkAutoApproval("tool", message)

        alt 自动批准
            Approval-->>Tool: shouldAutoApprove = true
        else 需要用户确认
            Tool->>User: ask("tool", completeMessage)
            User-->>Tool: yesButtonClicked / noButtonClicked
        end

        alt 用户批准
            Tool->>DiffView: saveDirectly(path, content, diagnosticsEnabled, writeDelayMs)
            DiffView->>FS: await delay(writeDelayMs)
            DiffView->>FS: fs.writeFile(path, content)
            FS-->>DiffView: 写入成功
        else 用户拒绝
            Tool->>Task: didRejectTool = true
            Tool->>Task: pushToolResult("Denied by user")
        end
    else 传统 Diff View 模式
        Tool->>DiffView: open(path)
        DiffView->>FS: fs.readFile(path)
        FS-->>DiffView: originalContent
        DiffView->>DiffView: 打开 VS Code Diff 编辑器

        Tool->>DiffView: update(content, isFinal=true)
        DiffView->>DiffView: 应用 WorkspaceEdit
        DiffView->>DiffView: 高亮差异

        Tool->>User: ask("tool", completeMessage)
        User-->>Tool: yesButtonClicked / noButtonClicked

        alt 用户批准
            Tool->>DiffView: saveChanges(diagnosticsEnabled, writeDelayMs)
            DiffView->>FS: await delay(writeDelayMs)
            DiffView->>FS: fs.writeFile(path, finalContent)
            FS-->>DiffView: 写入成功
            DiffView->>DiffView: 获取新诊断信息
            DiffView->>DiffView: 关闭 Diff 编辑器
        else 用户拒绝
            Tool->>DiffView: revertChanges()
            DiffView->>DiffView: 恢复原始内容
            DiffView->>DiffView: 关闭 Diff 编辑器
        end
    end

    Tool->>Tracker: trackFileContext(path, "roo_edited")
    Tracker->>Tracker: 添加到 task_metadata.json
    Tracker->>Tracker: 设置文件监听器 (FileSystemWatcher)

    Tool->>Task: pushToolResult("Successfully wrote to file")
    Task->>Task: userMessageContent.push({ type: "tool_result", content })

    Note over Task: 继续主循环，发送 tool_result 给 LLM
```

## 时序图 C: LLM 触发 tool call → MCP → result → 继续生成

```mermaid
sequenceDiagram
    participant LLM as LLM API
    participant Task as Task
    participant Parser as NativeToolCallParser
    participant McpHub as McpHub
    participant McpServer as MCP Server<br/>(外部进程)
    participant User as 用户

    Note over Task,LLM: LLM 决定调用 MCP 工具

    LLM->>Task: stream chunk (tool_call_partial)
    Task->>Parser: processRawChunk(chunk)
    Parser->>Parser: 解析工具名称: "mcp__server_name__tool_name"
    Parser-->>Task: tool_call_start event

    Task->>Task: assistantMessageContent.push({ type: "mcp_tool_use", name: "mcp__..." })

    LLM->>Task: stream chunk (tool_call_partial) [参数]
    Task->>Parser: processRawChunk(chunk)
    Parser->>Parser: 增量解析参数 JSON
    Parser-->>Task: tool_call_delta event

    LLM->>Task: stream end
    Task->>Parser: finalizeStreamingToolCall()
    Parser-->>Task: 完整的 McpToolUse

    Note over Task: 流式处理完成，开始执行 MCP 工具

    Task->>Task: executeTool(mcpToolUse)
    Task->>Task: executeMcpTool(mcpToolUse)

    Task->>Task: 解析工具名称 (提取 serverName 和 toolName)

    Task->>User: ask("mcp_server_request_approval", JSON.stringify({ server, tool, args }))

    alt 用户批准
        User-->>Task: yesButtonClicked

        Task->>McpHub: callTool(serverName, toolName, args)

        McpHub->>McpHub: 查找已连接的 MCP Server

        alt stdio 传输
            McpHub->>McpServer: stdin.write(JSON.stringify({ method: "tools/call", params }))
            McpServer->>McpServer: 执行工具逻辑
            McpServer->>McpHub: stdout (JSON-RPC response)
        else SSE 传输
            McpHub->>McpServer: POST /sse (JSON-RPC request)
            McpServer->>McpServer: 执行工具逻辑
            McpServer->>McpHub: Server-Sent Event (JSON-RPC response)
        else HTTP 传输
            McpHub->>McpServer: POST /call (JSON-RPC request)
            McpServer->>McpServer: 执行工具逻辑
            McpServer->>McpHub: HTTP response (JSON-RPC response)
        end

        McpHub-->>Task: toolResult (JSON)

        Task->>Task: 格式化工具结果
        Task->>Task: userMessageContent.push({ type: "tool_result", content: result })

    else 用户拒绝
        User-->>Task: noButtonClicked
        Task->>Task: didRejectTool = true
        Task->>Task: userMessageContent.push({ type: "tool_result", content: "Denied by user" })
    end

    Note over Task: 继续主循环，发送 tool_result 给 LLM

    Task->>Task: recursivelyMakeClineRequests([userMessageContent])
    Task->>Task: addToApiConversationHistory({ role: "user", content: [tool_result] })

    Task->>LLM: createMessage(systemPrompt, messages)
    LLM-->>Task: stream (继续生成)

    Note over Task,LLM: LLM 根据 tool_result 继续生成响应

    loop 流式处理
        LLM->>Task: chunk (text/reasoning/tool_call)
        Task->>Task: 处理 chunk
        Task->>Task: presentAssistantMessage()
    end

    Note over Task: 可能继续调用更多工具，或完成任务
```

- MCP 工具执行: `src/core/task/Task.ts:4400-4500`

- MCP 连接: `src/services/mcp/McpHub.ts:200-300`

## 补充时序：错误处理与重试

```mermaid
sequenceDiagram
    participant Task as Task
    participant API as LLM API
    participant Backoff as 指数退避

    Task->>API: createMessage(systemPrompt, messages)

    alt API 请求成功
        API-->>Task: stream (正常)
    else API 请求失败 (首次 chunk 前)
        API-->>Task: Error (429 Rate Limit / 500 Server Error)

        Task->>Task: consecutiveMistakeCount++

        alt 启用自动重试 (autoApprovalEnabled + alwaysApproveResubmit)
            Task->>Backoff: backoffAndAnnounce(retryAttempt, error)
            Backoff->>Backoff: 计算退避时间 (2^retryAttempt * 1000ms)
            Backoff->>Backoff: 最大 600 秒
            Backoff->>Task: say("error", "Retrying in X seconds...")
            Backoff->>Backoff: await delay(backoffMs)
            Backoff-->>Task: 退避完成

            Task->>Task: stack.push({ userContent, retryAttempt: retryAttempt + 1 })
            Task->>Task: continue (重试)
        else 手动重试
            Task->>Task: say("error", errorMessage)
            Task->>Task: 等待用户反馈
        end

    else 流式处理中失败
        API->>Task: chunk 1, chunk 2, ...
        API-->>Task: Error (连接断开)

        Task->>Task: abortStream("streaming_failed", errorMessage)
        Task->>Task: 保存部分消息

        alt 启用自动重试
            Task->>Backoff: backoffAndAnnounce(retryAttempt, error)
            Backoff-->>Task: 退避完成
            Task->>Task: stack.push({ userContent, retryAttempt: retryAttempt + 1 })
        else 手动重试
            Task->>Task: say("error", "Stream failed")
        end
    end
```

**关键文件依据**:

- 错误处理: `src/core/task/Task.ts:3221-3278`
- 指数退避: `src/core/task/Task.ts:3500-3600`
- 重试逻辑: `src/core/task/Task.ts:3268-3276`

## 性能关键点

### 1. 流式渲染优化

- **虚拟滚动**: 仅渲染可见消息 (Webview)
- **增量更新**: 使用 `partial=true` 标记增量消息
- **防抖**: UI 更新防抖 100ms

**依据**: `webview-ui/src/components/chat/ChatView.tsx:100`

---

### 2. 上下文管理优化

- **延迟压缩**: 仅在接近阈值时触发
- **非破坏性截断**: 标记隐藏而非删除
- **Token 预算**: 文件读取前检查 token 预算

**依据**: `src/core/context-management/index.ts:150`

---

### 3. 并发控制

- **单例任务**: 同一时间只有一个活跃 Task
- **串行工具执行**: 工具按顺序执行
- **流式锁**: `isStreaming` 标志防止并发流

**依据**: `src/core/task/Task.ts:2613`
