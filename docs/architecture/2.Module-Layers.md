## 模块依赖规则

### 允许的依赖方向

```
UI 层 → 编排层 (仅通过 postMessage)
编排层 → 工具层
编排层 → 集成层
工具层 → 集成层
工具层 → 基础设施层
集成层 → 基础设施层
```

### 禁止的依赖

```
✗ 工具层 → 编排层 (会导致循环依赖)
✗ 集成层 → 编排层 (会导致循环依赖)
✗ 基础设施层 → 任何上层 (违反分层原则)
```
