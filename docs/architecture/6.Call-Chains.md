## 性能优化路径

### 关键路径优化

**1. 首次 Token 时间 (TTFT)**:

```
用户输入 → postMessage (< 1ms)
  → processKiloUserContentMentions (< 100ms)
  → getEnvironmentDetails (< 500ms)
  → API 请求发送 (< 50ms)
  → 首次 chunk 返回 (< 2000ms)

总计: ~2.5 秒
```

**瓶颈**:

- `getEnvironmentDetails()` 中的文件列表生成 (500ms)
- API 网络延迟 (1-2 秒)

**优化建议**:

1. 缓存文件列表 (仅首次生成)
2. 使用更快的 LLM Provider
3. 启用 Prompt Cache

---

**2. 流式更新延迟**:

```
LLM 返回 chunk (< 50ms)
  → Task 处理 chunk (< 10ms)
  → postStateToWebview() (< 5ms)
  → Webview 渲染 (< 30ms)

总计: ~95ms
```

**优化建议**:

1. 批量更新 (每 100ms 一次)
2. 虚拟滚动优化
3. 使用 React.memo 减少重渲染
