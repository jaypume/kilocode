### 2.2 Provider 实现示例

**Anthropic**:

```typescript
// src/api/providers/anthropic.ts:80
async *createMessage(
  systemPrompt: string,
  messages: Anthropic.Messages.MessageParam[],
  metadata?: ApiHandlerCreateMessageMetadata
): ApiStream {
  const stream = await this.client.messages.create({
    model: this.options.apiModelId,
    max_tokens: metadata?.maxTokens || 8192,
    system: [
      { type: "text", text: systemPrompt, cache_control: { type: "ephemeral" } }
    ],
    messages: messages,
    tools: anthropicTools,
    stream: true
  })

  for await (const event of stream) {
    switch (event.type) {
      case "content_block_delta":
        if (event.delta.type === "text_delta") {
          yield { type: "text", text: event.delta.text }
        }
        break
      case "message_delta":
        if (event.usage) {
          yield {
            type: "usage",
            inputTokens: event.usage.input_tokens || 0,
            outputTokens: event.usage.output_tokens || 0
          }
        }
        break
    }
  }
}
```

**OpenAI**:

```typescript
// src/api/providers/openai.ts:100
async *createMessage(
  systemPrompt: string,
  messages: Anthropic.Messages.MessageParam[],
  metadata?: ApiHandlerCreateMessageMetadata
): ApiStream {
  const openaiMessages = convertToOpenAiMessages(messages)

  const stream = await this.client.chat.completions.create({
    model: this.options.apiModelId,
    max_tokens: metadata?.maxTokens || 4096,
    messages: [
      { role: "system", content: systemPrompt },
      ...openaiMessages
    ],
    tools: metadata?.tools,
    stream: true,
    stream_options: { include_usage: true }
  })

  for await (const chunk of stream) {
    const delta = chunk.choices[0]?.delta

    if (delta?.content) {
      yield { type: "text", text: delta.content }
    }

    if (delta?.tool_calls) {
      for (const toolCall of delta.tool_calls) {
        yield {
          type: "tool_call_partial",
          index: toolCall.index,
          id: toolCall.id,
          name: toolCall.function?.name,
          arguments: toolCall.function?.arguments
        }
      }
    }

    if (chunk.usage) {
      yield {
        type: "usage",
        inputTokens: chunk.usage.prompt_tokens,
        outputTokens: chunk.usage.completion_tokens
      }
    }
  }
}
```

## 接口版本兼容性

### 向后兼容策略

1. **消息格式**: 新增字段使用可选类型 (`field?: Type`)
2. **工具参数**: 支持 Legacy XML 和 Native JSON 双格式
3. **API 响应**: 使用 `ApiStreamChunk` 联合类型，支持扩展

### 破坏性变更

**需要主版本号升级的情况**:

- 删除必需字段
- 修改字段类型 (非向后兼容)
- 修改工具名称或参数结构

**示例**:

